# AI 绘画平台 API 文档

本接口文档提供了 AI 图像生成服务的完整接入指南，包含素材上传、任务提交、进度查询及资源管理等功能。

## 1. 接入说明

* **API 基础路径**: `https://www.foxtrai.com/api/generate` (请替换为实际域名)
* **认证方式**: 所有的 API 请求都需要在 Header 中携带 Token。
  * `Authorization: Bearer <Your_Access_Token>`
* **数据格式**: 请求与响应体默认为 JSON 格式 (`Content-Type: application/json`)。
* **字符编码**: UTF-8
* **UA和SecUa说明**：发出请求时必须带上真实浏览器UA和secUA，不知道是什么的可以让AI随便生成一个

## 2. 图片上传 (Upload)

为了提高传输效率并支持秒传，文件上传分为“预上传授权”和“实际文件传输”两个步骤。

### 2.1 获取上传授权 (Pre-Upload)

在上传图片前，需调用此接口检查文件是否已存在（秒传），或获取上传凭证。

* **接口路径**: `POST /image/upload`
* **功能描述**: 获取文件上传的目标 URL 和资源 ID。

**请求参数 (Body):**

| 参数名       | 类型     | 必填  | 说明                                        |
|:--------- |:------ |:--- |:----------------------------------------- |
| filename  | string | 是   | 文件名 (例如 `example.png`)，仅支持图片格式            |
| mime_type | string | 是   | 文件 MIME 类型 (例如 `image/png`, `image/jpeg`) |
| size      | int64  | 是   | 文件大小 (字节)，最大限制 4MB                        |
| hash      | string | 是   | 文件内容的 SHA256 哈希值 (64位小写)，用于秒传检测           |
| width     | int    | 是   | 图片宽度 (像素)，需 >= 256                        |
| height    | int    | 是   | 图片高度 (像素)，需 >= 256                        |

**响应参数:**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "asset_id": "1234567890",
    "upload_url": "https://storage.example.com/upload/signed-url...",
    "is_hit": false
  }
}
```

* **asset_id**: 资源的唯一标识，用于后续创建绘画任务。
* **upload_url**: 
  * 若不为空：请使用 **PUT** 方法将文件二进制流上传至该地址。
  * 若为空（且 `is_hit` 为 `true`）：表示触发秒传，无需上传文件，直接使用 `asset_id` 即可。
* **is_hit**: 是否命中秒传。

### 2.2 确认上传状态 (Check Status)

如果是通过 `upload_url` 上传的新文件，建议在上传完成后调用此接口，确认云端已成功接收并同步状态。

* **接口路径**: `GET /image`
* **功能描述**: 检查指定资源的就绪状态。

**请求参数 (Query):**

| 参数名      | 类型    | 必填  | 说明    |
|:-------- |:----- |:--- |:----- |
| asset_id | int64 | 是   | 资源 ID |

**响应示例:**
成功返回 200 OK，无特殊 Data 数据。若文件未就绪，接口将返回错误提示。

## 3. 绘画任务 (Drawing Tasks)

### 3.1 提交绘画任务 (Create Task)

* **接口路径**: `POST /image/task/create`
* **功能描述**: 提交一个新的 AI 绘画任务。

**请求参数 (Body):**

| 参数名             | 类型            | 必填  | 说明                                                                                    |
|:--------------- |:------------- |:--- |:------------------------------------------------------------------------------------- |
| prompt          | string        | 是   | 提示词，描述画面内容 (最大 20000 字符)                                                              |
| model           | string        | 是   | 模型标识 (例如 `nano-banana`, `nano-banana-pro` ,`nano-banana-pro-ultra`, `nano-banana-2`等) |
| input_asset_ids | array[string] | 否   | 参考图/垫图的资源 ID 列表 (通过上传接口获取)，最大数量为5                                                     |
| aspect_ratio    | string        | 否   | 图片宽高比 (例如 `1:1`, `16:9`, `3:4`, `auto`,`9:16`,`4:3`)                                  |
| resolution      | string        | 否   | 分辨率/画质 (默认 `1K`，有`2K`,`4K`)                                                           |
| safe_generation | boolean       | 否   | 是否开启生成保险 (默认 `false`)，开启后若被风控将会退款                                                     |

**响应示例:**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "2019280647855542272"
  }
}
```

### 3.2 获取任务详情 (Get Result)

* **接口路径**: `GET /image/task`
* **功能描述**: 查询单个任务的执行状态及结果。推荐在前端使用轮询机制（例如每 2-3 秒一次）直到状态变为 `success` 或 `failed`。

**请求参数 (Query):**

| 参数名     | 类型     | 必填  | 说明    |
|:------- |:------ |:--- |:----- |
| task_id | string | 是   | 任务 ID |

**响应参数 (Data 结构):**

```json
{
  "id": "2019280647855542272",
  "status": "success",
  "progress": 100,
  "prompt": "A cute cat...",
  "model": "nano-banana",
  "error_msg": "",
  "created_at": "2023-10-27T10:00:00Z",
  "edges": {
    "outputs": [
      {
        "id": "55667788",
        "url": "https://storage.example.com/result.png?token=...",
        "media_type": "image",
        "width": 1024,
        "height": 1024,
        "mime_type": "image/png"
      }
    ],
    "inputs": []
  }
}
```

* **status**: 任务状态
  * `pending`: 排队中
  * `processing`: 生成中
  * `success`: 成功
  * `failed`: 失败
* **outputs.url**: 图片下载链接（通常包含签名，具有时效性，请勿永久存储链接）。

### 3.3 获取任务列表 (List Tasks)

* **接口路径**: `GET /image/tasks`
* **功能描述**: 分页获取历史绘画任务记录。

**请求参数 (Query):**

| 参数名        | 类型     | 必填  | 说明                                                  |
|:---------- |:------ |:--- |:--------------------------------------------------- |
| page       | int    | 否   | 页码，默认 1                                             |
| size       | int    | 否   | 每页条数，默认 10，最大 50                                    |
| status     | string | 否   | 状态筛选 (`pending`, `processing`, `success`, `failed`) |
| model      | string | 否   | 模型名称 (支持模糊匹配)                                       |
| start_time | int64  | 否   | 开始时间 (Unix 时间戳)                                     |
| end_time   | int64  | 否   | 结束时间 (Unix 时间戳)                                     |

**响应示例:**

```json
{
  "total": 50,
  "items": [
    { "id": "...", "status": "success", "prompt": "...", "edges": { "outputs": [...] } },
    { "id": "...", "status": "processing", "prompt": "...", "edges": { "outputs": [] } }
  ]
}
```

## 4. 资源管理 (Assets Management)

管理用户上传的参考图以及生成的作品图片。

### 4.1 获取资源列表 (List Assets)

* **接口路径**: `GET /image/assets`
* **功能描述**: 查询当前用户的图片资源。

**请求参数 (Query):**

| 参数名        | 类型     | 必填  | 说明                                        |
|:---------- |:------ |:--- |:----------------------------------------- |
| page       | int    | 否   | 页码                                        |
| size       | int    | 否   | 每页条数 (最大 60)                              |
| media_type | string | 否   | 固定为 `image`                               |
| source     | string | 否   | 来源: `generated` (生成结果), `uploaded` (用户上传) |
| asset_id   | string | 否   | 按 ID 精确查询                                 |

**响应示例:**

```json
{
  "total": 120,
  "items": [
    {
      "id": "123",
      "url": "https://storage...",
      "width": 1024,
      "height": 1024,
      "created_at": "..."
    }
  ]
}
```

### 4.2 删除资源 (Delete Asset)

* **接口路径**: `DELETE /image/asset`
* **功能描述**: 删除指定的图片资源（包括数据库记录及云端文件）。

**请求参数 (Body):**

```json
{
  "asset_id": "1234567890"
}
```

**响应**: 成功返回 200 OK。

## 5. 错误码说明

接口返回非 200 状态码或 JSON 中 `code != 0` 时，请参考 `message` 字段。

| HTTP Status | 说明                    |
|:----------- |:--------------------- |
| **400**     | 参数错误 / 余额不足 / 文件格式不支持 |
| **401**     | 身份认证失败 (Token 无效或过期)  |
| **429**     | 请求过于频繁 (触发限流)         |
| **500**     | 服务器内部错误               |
| **503**     | 服务暂时不可用 (如上传队列已满)     |
